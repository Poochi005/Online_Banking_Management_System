# Online Banking Management System (OBMS)

A beginner-friendly Java 17 + JDBC + MySQL console project using a simple layered structure.

## Features
- Create and view customer bank accounts
- Deposit and withdraw money
- Transfer money between accounts
- View transaction history
- Input validation and database transactions for money transfers

> Educational demo only. It is not production banking software: it does not implement real authentication, encryption, regulatory controls, or bank-grade security. Never use real banking credentials or money.

## Requirements
- JDK 17+
- Maven 3.8+
- MySQL 8+

## 1. Create the database
Open MySQL Workbench or the MySQL command line and run `database/obms.sql`.

## 2. Configure database connection
Set environment variables before running (PowerShell example):
```powershell
$env:OBMS_DB_URL="jdbc:mysql://localhost:3306/obms"
$env:OBMS_DB_USER="root"
$env:OBMS_DB_PASSWORD="YOUR_MYSQL_PASSWORD"
```
If you do not set them, defaults are `jdbc:mysql://localhost:3306/obms`, `root`, and an empty password. Change these in `src/main/java/com/obms/config/DBConnection.java` if preferred.

## 3. Run from the project folder
```powershell
mvn clean compile
mvn exec:java
```

## Project structure
- `model/` — data objects
- `repository/` — JDBC/database operations
- `service/` — business rules
- `config/` — database connection
- `App.java` — console menu
- `database/obms.sql` — schema

## Sample workflow
1. Create two accounts from the menu and note their account IDs.
2. Deposit money into one account.
3. Transfer money to the other account using account IDs.
4. View transaction history.

Account IDs are generated by MySQL. Use the IDs shown by the app.
